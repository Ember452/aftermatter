# ADR-0004: 比较边界强制声明（F4，P0）

日期: 2026-09-21 | 状态: accepted

## 背景
原版 History 视图截图核实：其趋势展示仅有一行免责文本
（"this is a report trend, not causal proof"），机制上无匹配、无混杂控制、无统计检验。
我们若只抄趋势图，等于把最容易被戳穿的软肋带进自己的报告。

## 决定
任何趋势/纵向比较输出必须携带机器可读的 `Comparability + Verdict`
（可比性置信度、被排除的混杂及理由、是否因果、样本缺口 missing_n）；
缺边界声明的比较块由 report-quality 校验器拒绝渲染，禁止裸 Δ 分数出现在报告中。

## 影响
PRD FR-F4（P0）；T2.6 校验器、T5.5–T5.7 匹配/混杂/统计模块的输出口径；
"证据不足"是合法终态而非失败（对齐 PRD R2 对策）。
