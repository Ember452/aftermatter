# specs/ — 专题决策与设计文档

命名：`YYYY-MM-DD-<主题>[-adr].md`（日期前缀，时效性强，写完不追改；被推翻时新起一份并互相引用）。

收录标准：一次性的、需要完整背景与边界论证的决策/设计文档（如双大脑架构确立、
纵向验证统计方案选型、宿主格式漂移应对策略）。
一页能写完的轻量决策去 `../adr/`；长期维护的契约写进 `../architecture/`。

**不收里程碑收口报告**："做完了、选了什么、证据是什么"那类记录属于 `../reports/`（ADR-0014），
混进来会让本目录从"决策全论证"退化成"任何带日期的文档"。
