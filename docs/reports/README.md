# reports/ — 里程碑收口报告

收录**里程碑/阶段完成后的收口报告**：做了什么、选了什么与否掉了什么、文件清单、
验证证据、计划外发现、遗留问题、对下一阶段的交接（目录设立见 ADR-0014）。

命名：`m<N>-<kebab-slug>.md`，如 `m0-skeleton-completion-report.md`；
收口日期写在头部元数据，不进文件名。

每篇固定骨架（可增不可删）：

```
状态: 定稿（一次性收口记录，写完不追改） | 日期 | 对应
定位声明：当前阶段状态以 ../plans/ROADMAP.md 的「§1 当前阶段快照」为准，本文只作历史证据
0. 一句话结论  → 1. 任务对照（计划/实际/验收） → 2. 提交序列 → 3. 选型与被否方案
→ 4. 文件清单 → 5. 实现了什么（含明确未实现） → 6. 验证证据（真实命令输出）
→ 7. 计划外发现 → 8. 遗留问题与处置 → 9. 下一阶段交接
```

纪律：

- **不维护时效性内容**——阶段状态、"下一步做什么"只写在 ROADMAP §1，这里重复即双写；
- 证据必须是**实际执行过的命令输出**，不写转述、不写预期结果；做不到的小节直接写"未验证"；
- 写完不追改；结论被后续事实推翻时，在新报告里引用并更正，不回改旧报告。
