# tests/ — 量化指标实测文档

收录**需要人工实测/真实环境验证**的指标场景（自动化测试覆盖不到的），
命名：`指标测试-<模块>.md`（如 `指标测试-解析器正确率.md`、`指标测试-假阳性率.md`）。

这里的中文文件名是 ADR-0013 明确批准的**全仓唯一豁免**（理由：一份报告对应 PRD §9
的一个中文指标名，文件名即检索入口），由 `policy_checker` 机器化；`docs/` 其他子目录
仍按 ADR-0011 要求英文名。

每篇固定结构：目的 → 环境 → 步骤 → 数据记录表 → 结论（对应 PRD §9 哪个指标）。

注意：与仓库根的 `tests/`（代码测试）是两回事，这里是"实测报告"的存放处。
